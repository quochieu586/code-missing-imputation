# Chạy từ notebook

Gọi CLI theo [README gốc](../README.md). Dùng kernel từ môi trường `.venv` hiện hành và truyền đường dẫn tuyệt đối nếu thư mục làm việc của notebook khác gốc repo.

Giữ logic dữ liệu, model và đánh giá trong `src/longitudinal_impute/`. Thư mục này chưa có notebook cần duy trì. Notebook và báo cáo của hướng nghiên cứu cũ nằm trong [archive](../archive/README.md).
